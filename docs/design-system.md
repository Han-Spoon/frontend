## 레이아웃

모바일 중심 최대 너비 430px. 화면은 헤더·독립 스크롤 본문·하단 내비게이션/CTA로 구성한다. 기본 좌우 여백 20px, 섹션 간격 24–32px, 카드 라운드 20–24px, 컨트롤 최소 높이 44px. RTL은 start/end, ms/me, ps/pe를 우선한다.

홈은 편집형 제목 → 큰 이미지 자동 캐러셀 → 촬영 진입 → 지역 지도 미리보기 → 식당 추천 순서다. 24–30px의 큰 라운드, 이미지 위 그라디언트, 떠 있는 원형 행동 버튼을 써 여행 앱처럼 몰입감 있게 구성하되 기존 브랜드 색을 유지한다. 메인 화면에 검색 입력부터 강요하지 않는다. 이름 검색은 식당 선택 시트에 둔다.

식당 상세는 풀스크린 지도 위 바텀시트로 표현한다. 지도 핀을 눌렀을 때 상세가 열리고, 닫으면 지도 맥락을 그대로 유지한다. 입점 파트너의 `전체 레시피 인증` 배지는 브랜드 초록색을 사용하며, 개인별 식단 안전을 의미하는 상태 배지와 혼동하지 않도록 별도 설명을 제공한다.

온보딩은 짙은 잉크 배경, 단계별 분절 진행 바, 중앙 정렬한 큰 질문, 둥근 선택 칩, 흰색 하단 CTA를 사용한다. 선택 상태는 브랜드 초록으로 표시하며 언어·국가·식단 프로필의 기존 입력 계약은 바꾸지 않는다.

랜딩은 한식 사진을 화면 가득 사용하고 짙은 초록 그라디언트로 텍스트 대비를 확보한다. 큰 한 문장, 세 개의 짧은 핵심 기능, 흰색 pill CTA로 첫 행동을 명확히 한다. 로그인은 사진 상단과 쌀빛의 둥근 하단 시트를 겹치며 Google 공식 버튼 하나만 제공한다. 이메일·비밀번호 입력창이나 연결되지 않은 소셜 버튼을 장식으로 두지 않는다.

## 식당 추천과 큐레이션

조건별 랭킹 대신 ‘HAN SPOON PICKS / 한 끼가 여행이 되는 곳’을 표시한다. 밝은 바탕, 큰 세로 사진, 하단 그라디언트와 상호·업종·주소, 44px 원형 이동 버튼을 사용한다. 선택 지역의 실제 식당 후보를 가로 스크롤로 탐색하고 클릭하면 지도에서 확인한다. 사진은 API 사진 계약 전까지 명시적인 참고 이미지이며 순위·평점·안전 비율을 표시하지 않는다.

큐레이션 목록과 상세는 짙은 초록(#13231c) 위에 큰 사진과 하단 그라디언트, 쌀빛 타이포, 28px 라운드를 사용하는 에디토리얼 화면이다. 제목보다 사진만 강조하지 않도록 목록에 한 문장 요약을 함께 둔다. 원고와 썸네일의 의미가 맞아야 하며 이미지 로딩 실패 시 다른 사진으로 대체하지 않고 안내한다. 홈 캐러셀도 동일한 글의 사진을 사용한다.

하단 글로벌 내비게이션은 홈 / 큐레이션 / 촬영 / 지도 / 카드. 기록은 마이페이지에 남겨두고, 지도 탭에서는 현재 위치 기반 탐색을 시작한다.

## 결과 카드

2026-09-15: 주의 영역은 재료별 원형 포함 가능성 그래프를 사용한다. 펼친 근거는 재료별 출처·근거 수준, 연결 경로, 확인 체크리스트로 구분한다. 네 분석 관점 카드와 ‘근거를 한눈에’ 제목은 제거했다. 가격 아래에는 음식 설명만 표시한다. 직원 응답은 의미와 무관하게 선택 시 같은 브랜드 초록색이며 식단 판정 색상과 분리한다.

메뉴 이름을 중심으로 이미지·상태·라이킷을 배치한다. 원화 가격을 기본으로 표시하고 환산 가격에는 ≈를 붙인다. 핵심 이유는 접지 않는다. caution에서만 프로필과 연결된 회피 재료의 포함 가능성을 수치/막대로 노출한다.

근거·출처·숨은 재료 경로는 사용자가 펼칠 수 있다. agent 개수나 내부 오케스트레이션을 메뉴 선택에 필요한 정보보다 앞세우지 않는다. 모든 메뉴 뒤에 에디토리얼 추천을 한 번 배치한다.

저장과 재촬영은 동일 너비·높이로 제공하며 저장은 채움, 재촬영은 테두리로 구분한다. 라이킷은 메뉴 선호, 기록 저장은 스캔 보관으로 의미를 분리한다.
