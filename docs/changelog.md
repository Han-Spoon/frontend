# 변경 기록

## 2026-09-14 — 랜딩 실사 이미지 정리

- 랜딩의 야시장 전경을 한국 식당에서 여러 음식을 함께 경험하는 Unsplash 실사 사진으로 교체.
- 이미지 생성 자산 없이 원본 사진 URL을 사용하고 출처와 라이선스를 demo-guide에 기록.

## 2026-09-14 — 발견 랭킹·큐레이션·지도 탭·등록 메뉴

- 병합된 최신 main에서 `codex/discovery-curation-refresh`로 분리해 작업.
- 홈 랭킹을 채식 유형/알레르기/종교 기준과 세부 조건으로 구분. 조건별 요청 전달 만족 비율, 응답 수, 지역·음식 유형·가격·입점 상태 표시.
- 큐레이션 22편 전체 사진을 감사하고 8개 새 사진 자산 적용. 짙은 초록의 큰 사진 카드·상세 에디토리얼 UI와 일관된 홈 캐러셀 이미지 연결.
- 글로벌 기록 탭을 `/map` 지도 탭으로 교체. 이전 지도 경로는 쿼리 보존 리다이렉트, 기록 페이지는 마이페이지에서 유지.
- 홈의 내 주변 버튼 제거. 지도 탭에서 일회성 위치 조회, 주변 fixture 거리 정렬, 위치 실패와 주변 후보 없음 상태 처리.
- 입점 식당은 6종 가상 등록 레시피를 현재 프로필과 비교하여 촬영 없이 결과 표시. 실제 스캔 API는 유지.
- 지도 SDK 인증 실패 후 페이지를 나갈 때 SDK 객체 정리 오류로 화면이 비던 문제 방어.

## 2026-09-14 — 브랜드 랜딩과 Google 로그인

- `/`에 풀블리드 한식 사진과 핵심 가치, 단일 CTA로 구성한 모바일 랜딩 추가.
- `/login`을 사진 히어로와 둥근 로그인 시트 구조로 개편하고 Google 로그인만 제공.
- 기존 Google ID Token·프로필 존재 여부에 따른 home/onboarding 분기 계약 유지.
- 랜딩·로그인에서 7개 언어 선택과 아랍어 RTL을 유지하고 신규 문구 임시 번역 추가.

## 2026-09-14 — Naver 지역 지도 연결

- 홈의 지역 지도 미리보기와 `/restaurants/map` 풀스크린 개략도를 Naver Maps SDK `StoreMap`으로 교체.
- 18개 지역별 가상 식당 좌표를 임시 핀으로 표시하고 핀 선택을 기존 식당 카드·상세 시트와 연결.
- 운영 DB 좌표가 준비되면 `StoreMap`의 `stores` 입력만 교체할 수 있도록 렌더링 계약 유지.
- PR 병합 충돌 과정에서 누락된 식당 선택 시트의 `StoreMap` import 복구.

## 2026-09-14 — 홈 발견 경험과 풀스크린 지도

- 기존 브랜드 색상은 유지하면서 큰 이미지, 30px 라운드 카드, 떠 있는 행동 버튼 중심으로 홈 화면 개편.
- 캐러셀·지도 기반 발견·식단별 랭킹의 세 구성을 유지하고 캐러셀을 5개/5초 자동 재생으로 확장.
- 마지막 슬라이드 뒤 복제 슬라이드를 사용해 첫 슬라이드로 정방향 순환하도록 개선.
- 18개 지역과 지역별 식당 3곳의 데모 데이터 추가.
- `/restaurants/map` 풀스크린 지도와 핀 선택형 식당 상세 바텀시트 추가.
- 식당·지역 검색바와 지도 하단 카드의 카테고리·1인 예상 가격·식단 경험 정보를 추가하고 핀 번호/데모 문구 제거.
- 일반 등록 표시는 생략하고 한스푼 입점 및 전체 레시피 인증 식당만 배지로 구분.
- 큐레이션 12편의 벡터 자리표시자를 주제별 공개 라이선스 사진으로 교체.
- 온보딩을 분절 진행 바·큰 질문·선택 칩·하단 흰색 CTA 중심의 몰입형 화면으로 개편.
