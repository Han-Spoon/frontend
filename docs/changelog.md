## 2026-09-14 — 발견 랭킹·큐레이션·지도 탭·등록 메뉴

- 병합된 최신 main에서 `codex/discovery-curation-refresh`로 분리해 작업.
- 홈 랭킹을 채식 유형/알레르기/종교 기준과 세부 조건으로 구분. 조건별 요청 전달 만족 비율, 응답 수, 지역·음식 유형·가격·입점 상태 표시.
- 큐레이션 22편 전체 사진을 감사하고 8개 새 사진 자산 적용. 짙은 초록의 큰 사진 카드·상세 에디토리얼 UI와 일관된 홈 캐러셀 이미지 연결.
- 글로벌 기록 탭을 `/map` 지도 탭으로 교체. 이전 지도 경로는 쿼리 보존 리다이렉트, 기록 페이지는 마이페이지에서 유지.
- 홈의 내 주변 버튼 제거. 지도 탭에서 일회성 위치 조회, 주변 fixture 거리 정렬, 위치 실패와 주변 후보 없음 상태 처리.
- 입점 식당은 6종 가상 등록 레시피를 현재 프로필과 비교하여 촬영 없이 결과 표시. 실제 스캔 API는 유지.
- 지도 SDK 인증 실패 후 페이지를 나갈 때 SDK 객체 정리 오류로 화면이 비던 문제 방어.
