# 다국어와 접근성

언어: ko, en, ar, zh-CN, ja, zh-TW, es. `locales.ts`의 LANGUAGE_CODES/LOCALES/OPTIONS를 원본으로 사용한다. 기존 서버 언어 enum은 ko/en/ar라서 나머지는 로컬 선택을 보존하고 서버 요청에 fallback한다.

## 번역

기존 createTranslator와 translateText를 사용한다. 새 화면은 ko/en/ar 문구가 있으며 신규 핵심 컨트롤은 간체·일본어·번체·스페인어 임시 번역을 추가한다. 새 큐레이션 12편은 ko/en/ar 본문을 제공하고 나머지 언어의 장문은 영어 fallback이다. 최종 번역 완료로 표현하지 않는다.

식당은 한글 원명과 영문 별칭을 보유한다. 모든 상호를 번역해서 별개 식당으로 저장하지 않는다. 검색은 canonical ID에 연결된 alias 인덱스를 향후 확장한다. 데모 검색은 이름과 지역의 부분 일치다.

이는 제품 데모의 기본 매핑이다. 영어=미국, 아랍어=사우디 국적을 뜻하지 않는다. 실서비스는 언어와 별개인 통화 선택이 필요하다. 원화를 항상 유지한다. 범위 가격이나 인원 조건이 섞인 문자열은 임의로 숫자를 붙여 계산하지 않는다.

화면의 매일 00시 안내는 고정 환율 시연용 문구이며 실제 배치 작업은 없다. demo-guide를 참조한다.

## RTL·접근성

ar에서 html dir=rtl. 포털 바텀시트는 자체 dir도 지정한다. 지도 좌표는 방향에 따라 뒤집지 않고 글자와 컨트롤을 RTL로 배치한다. 가격은 독립적인 ltr 영역에서 유지한다.

Radix Dialog 기반 시트는 제목·설명, 포커스 이동/복귀, Escape 닫기, 배경 차단을 제공한다. 하트/핀/필터는 aria-label 또는 aria-pressed를 제공한다. 라디오 후기는 fieldset/legend로 묶는다. 상태는 색상만으로 구분하지 않고 텍스트와 아이콘을 함께 쓴다.

320/390/430px, 긴 번역, 확대, 키보드 포커스, reduced-motion을 검증한다. 장문 영어 fallback은 RTL에서도 섞일 수 있으므로 최종 아랍어/타 언어 편집 검토가 필요하다.
