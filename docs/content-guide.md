# 큐레이션 편집 원칙

결과 화면에서 사용자의 첫 목적은 메뉴 선택이다. 메뉴 사이에 콘텐츠 카드를 끼우지 않는다. 마지막 메뉴 뒤에 관련 글 최대 3개를 중복 없이 추천한다. 홈과 큐레이션 탭에서는 탐색을 위한 별도 에디토리얼로 제공한다.

## 신규 글 12편

| ID | 제목 |
| --- | --- |
| sauce-on-side | 소스는 따로, 취향은 가까이 |
| market-small-plates | 시장에서 시작하는 작은 한 입 |
| solo-table | 혼자여도 좋은 한국의 식탁 |
| broth-question | 국물 속 이야기를 물어보세요 |
| seongsu-walk | 성수, 산책과 한 끼 사이 |
| busan-seaside | 부산에서는 바다 곁 한 끼 |
| spice-conversation | 덜 맵게, 더 즐겁게 |
| banchan-questions | 작은 반찬, 하나씩 알아가기 |
| cafe-pause | 카페에서 쉬어가는 한 페이지 |
| halal-conversation | 내 식단을 설명하는 첫 문장 |
| menu-memory | 맛있는 기억을 모으는 방법 |
| ordering-rhythm | 주문부터 계산까지, 천천히 |

각 글은 한국어·영어·아랍어 제목/요약/3문단 본문을 갖는다. 기존 글은 유지한다. 4개 추가 언어의 신규 본문 번역은 후속 작업이다.

## 앞으로 추가할 것

지역별 여행 동선, 한글 메뉴 읽는 법, 계절 음식, 식단 요청 대화 예시, 파트너 인터뷰. ID는 바꾸지 않으며 제목/본문 수정 시 번역도 함께 검토한다. source/author/updatedAt/번역 상태를 CMS 계약에 추가할 예정이다.

광고·제휴 글을 도입할 경우 일반 에디토리얼과 구분한다. 건강효과·알레르기 안전·종교 인증을 콘텐츠 작성자가 임의로 단정하지 않는다. 실제 식당의 추천은 현장 정보와 출처를 검증한 뒤 발행한다.
