# 한스푼 브랜드 가이드

> Version 0.1 · AI·SW중심대학 우수작품경진대회 UI/UX 리뉴얼

## 1. 브랜드 정의

### 브랜드명

- 국문: **한스푼**
- 영문: **Han Spoon**
- 코드·저장소 표기는 기존 명칭을 유지하되, 사용자 화면에서는 위 표기를 일관되게 사용한다.

### 지원 언어

- 한국어
- 영어
- 아랍어
- 중국어(간체)
- 일본어
- 중국어(번체)
- 스페인어

### 브랜드 한 문장

**낯선 한국 메뉴도 안심하고 발견하도록 돕는 가장 친근한 여행 식탁 가이드**

### 브랜드 철학

한스푼은 언어와 식문화의 차이 때문에 한국 음식을 고르는 일이 불안한 경험이 되지 않아야 한다고 믿는다. 메뉴의 의미와 식이 위험 정보를 이해하기 쉽게 전하고, 필요한 말을 식당에 정확히 전달할 수 있도록 도와 사용자가 자신의 기준에 맞는 음식을 안심하고 발견하게 한다.

### 브랜드 약속

**낯선 메뉴도, 안심하고 한 스푼.**

### 핵심 가치

1. **안심** — 알레르기·종교·채식 등 사용자의 식이 기준을 명확하고 신중하게 안내한다.
2. **발견** — 제한 사항만 보여주는 데 그치지 않고, 먹을 수 있는 한국 음식의 즐거움을 넓힌다.
3. **연결** — 사용자와 식당 사이의 언어 장벽을 낮추고 필요한 의사소통을 돕는다.

## 2. 브랜드 성격

한스푼은 딱딱한 번역 도구나 경고 중심의 건강 앱이 아니다. 믿을 수 있는 정보를 주면서도 새로운 음식을 함께 찾아주는 친근한 한국 여행 동반자다.

| 성격 | 표현 방식 | 피해야 할 방식 |
| --- | --- | --- |
| 믿음직한 | 근거와 상태를 명확히 설명한다 | 과장된 안전 보장, 모호한 단정 |
| 친근한 | 짧고 쉬운 말, 부드러운 존댓말을 쓴다 | 지나친 유행어, 유아적인 말투 |
| 호기심 많은 | 먹을 수 있는 메뉴와 새로운 맛을 제안한다 | 위험·제한 정보만 강조 |
| 세심한 | 문화·종교·식이 차이를 존중한다 | 특정 문화를 고정관념으로 표현 |

## 3. 핵심 메시지

### 대표 슬로건

**낯선 메뉴도, 안심하고 한 스푼.**

### 보조 문구 후보

- 한국의 맛을 이해하는 가장 쉬운 방법
- 안심은 더하고, 낯섦은 덜고
- 나에게 맞는 한국 음식을 발견해 보세요
- 메뉴판 한 장으로 시작하는 맛있는 한국 여행

### 메시지 우선순위

1. 사용자의 식이 기준에 맞는지 이해할 수 있다.
2. 한국어 메뉴가 무엇인지 쉽게 알 수 있다.
3. 먹고 싶은 메뉴를 발견할 수 있다.
4. 필요한 내용을 식당에 정확히 전달할 수 있다.

## 4. 보이스 앤 톤

### 기본 원칙

- 한 문장에는 하나의 행동이나 정보만 담는다.
- 사용자가 다음에 무엇을 하면 되는지 먼저 알려준다.
- 위험을 과장해 겁주지 않고, 이유와 대응 방법을 함께 보여준다.
- 번역투보다 여행 중 실제로 이해하기 쉬운 자연스러운 문장을 사용한다.
- 한국어·영어·아랍어·중국어(간체·번체)·일본어·스페인어에서 의미와 친절함의 수준을 동일하게 유지한다.

### 문구 예시

| 상황 | 권장 문구 | 피해야 할 문구 |
| --- | --- | --- |
| 촬영 유도 | 메뉴판을 찍으면 먹을 수 있는 메뉴를 찾아드려요 | 이미지를 업로드하여 분석을 실행하세요 |
| 안전 | 알레르기 성분이 포함될 수 있어요 | 위험! 섭취 금지 |
| 발견 | 안심하고 선택할 수 있는 메뉴 4개를 찾았어요 | 안전 메뉴 분석 완료 |
| 오류 | 사진이 흐려 메뉴를 읽기 어려워요. 다시 찍어볼까요? | OCR 처리 실패 |
| 대기 | 메뉴 속 재료를 꼼꼼히 살펴보고 있어요 | 분석 중입니다 |

## 5. 로고 방향

### 최종 로고

- 사용자 확정본 `src/assets/brand/han-spoon-logo.svg`를 제품의 단일 기준 원본으로 사용한다.
- 국문 워드마크를 중심으로 하며, 둥글고 단순한 글자 형태 안에 밥그릇과 숟가락 모티프를 결합한다.
- 별도의 반짝임 장식은 사용하지 않는다.
- 로고 주변에는 로고 높이의 최소 1/4만큼 여백을 확보하고, 비율을 변형하거나 임의로 다시 색칠하지 않는다.

### 로고 모티프

- **밥그릇**: 한 끼, 포용, 사용자의 식이 기준을 안전하게 담는 그릇
- **숟가락**: 한스푼이라는 이름, 맛을 발견하는 첫 행동, 사용자와 한국 음식을 잇는 매개

### 사용 원칙

- 둥글고 단순한 실루엣과 글자 획의 균형을 유지한다.
- 귀여움은 표정이나 복잡한 캐릭터보다 비율, 곡선, 색상에서 만든다.
- 음식 배달 서비스보다 **여행 식탁 가이드**로 인식되도록 배달·속도 상징은 사용하지 않는다.
- 화면에서는 SVG 원본을 사용하고, 비트맵이 필요한 경우에만 목적 크기에 맞춰 파생 파일을 만든다.

### 시각적 이미지

**따뜻한 밥그릇 + 한 끼를 안내하는 숟가락 + 둥글고 편안한 워드마크**

## 6. 컬러 시스템

따뜻한 한국 음식의 인상과 건강한 신뢰를 함께 전달한다. 초록은 주요 행동과 신뢰에, 주황은 발견과 즐거움에 사용한다.

| 토큰 | 색상 | 역할 |
| --- | --- | --- |
| Spoon Green 700 | `#176B4D` | 주요 버튼, 선택 상태, 핵심 브랜드 색상 |
| Spoon Green 500 | `#2F8F68` | 아이콘, 보조 강조, 일러스트 |
| Tangerine 500 | `#F4773B` | 발견, 즐거움, 작은 포인트 |
| Rice Cream | `#FFF8EA` | 기본 배경, 따뜻한 여백 |
| Rice White | `#FFFCF7` | 카드와 표면 |
| Soy Ink | `#242621` | 제목과 본문 |
| Sesame Gray | `#6D716B` | 보조 텍스트 |
| Border Warm | `#E7E2D7` | 경계선과 구분선 |

### 컬러 사용 규칙

- 흰색 글자를 사용하는 주요 버튼에는 `Spoon Green 700`을 사용한다.
- `Spoon Green 500`과 `Tangerine 500`은 흰색 본문을 올리지 않고 아이콘, 배경 면, 일러스트 포인트에 사용한다.
- `Tangerine 500` 위에는 `Soy Ink` 계열의 어두운 글자를 사용한다.
- 밝은 브랜드 색상을 텍스트 색으로 사용할 때는 작은 본문보다 큰 제목이나 아이콘에 한정하고 실제 화면에서 대비를 다시 검증한다.

### 상태 색상

상태 색상은 브랜드 강조색과 의미를 혼동하지 않도록 아이콘·레이블·설명을 함께 사용한다. 색상만으로 상태를 구분하지 않는다.

| 상태 | 색상 | 의미 |
| --- | --- | --- |
| Safe | `#21865D` | 현재 정보 기준으로 선택 가능 |
| Caution | `#B56A00` | 재료나 조리법 확인 필요 |
| Danger | `#C83C35` | 사용자 식이 기준과 충돌 |
| Info | `#3478B8` | 일반 안내와 추가 정보 |

`Caution` 색상 위에는 흰색 작은 글자를 사용하지 않는다. 연한 주의 배경과 어두운 주의 텍스트를 조합하고, 최종 컴포넌트 단계에서 대비를 다시 검증한다.

## 7. 타이포그래피

### 기본 서체

- 한국어·영어·스페인어: **Pretendard Variable**
- 중국어(간체): **PingFang SC / Microsoft YaHei / Noto Sans SC**
- 중국어(번체): **PingFang TC / Microsoft JhengHei / Noto Sans TC**
- 일본어: **Hiragino Sans / Yu Gothic / Noto Sans JP**
- 아랍어: **Noto Sans Arabic / Tahoma / Arial**
- 로고타입: 별도 장식 서체보다 둥근 인상의 커스텀 레터링을 우선한다.

Pretendard는 앱에 포함된 웹폰트로 제공한다. 중국어·일본어·아랍어는 운영체제 기본 서체를 우선 사용하고 Noto 계열을 폴백으로 둬 초기 다운로드 부담을 줄인다. 귀여운 인상은 과도한 장식 서체보다 굵기 대비와 둥근 컴포넌트로 만든다. 언어별 글자 크기를 기계적으로 동일하게 맞추기보다 실제 시각 크기와 행간을 조정한다.

### 타입 스케일

| 용도 | 크기 / 행간 | 굵기 |
| --- | --- | --- |
| Display | 32 / 40 | 800 |
| Page title | 24 / 32 | 700 |
| Section title | 20 / 28 | 700 |
| Body large | 18 / 28 | 500 |
| Body | 16 / 24 | 400 |
| Label | 14 / 20 | 600 |
| Caption | 12 / 18 | 500 |
| Button | 16 / 24 | 700 |

## 8. UI 스타일 원칙

### 형태

- 기본 간격 단위: 4px
- 화면 좌우 여백: 20px
- 카드 모서리: 16px
- 주요 버튼 모서리: 14px
- 강조 카드·바텀시트: 24px
- 칩과 상태 레이블: 완전한 pill 형태

### 깊이

- 선명한 그림자보다 따뜻한 배경과 얇은 경계선으로 영역을 구분한다.
- 떠 있는 주요 행동 버튼에만 절제된 그림자를 사용한다.
- 한 화면에서 강조 수준을 세 단계 이상 사용하지 않는다.

### 아이콘과 일러스트

- 아이콘은 둥근 선과 일관된 2px 내외의 굵기를 사용한다.
- 음식·여행·발견을 보여주는 단순한 플랫 일러스트를 사용한다.
- 장식 요소는 정보를 가리지 않는 범위에서만 사용한다.
- 알레르기와 위험 상태에는 장식적인 귀여움보다 명확성을 우선한다.

### 모션

- 기본 전환 시간: 160–240ms
- 촬영 후 분석 과정은 작은 단계 변화와 친근한 문구로 기다림을 설명한다.
- 안전 상태나 오류에는 튀는 애니메이션을 사용하지 않는다.
- 사용자의 `prefers-reduced-motion` 설정을 존중한다.

## 9. 다국어·접근성 원칙

- 지원하는 7개 언어에서 버튼과 카드가 번역문 길이에 따라 자연스럽게 늘어나야 한다.
- `lang` 속성에 따라 언어별 서체를 적용하고, 중국어 간체와 번체를 서로 다른 로케일과 폰트로 구분한다.
- 아랍어 선택 시 문서 방향과 주요 레이아웃을 RTL로 전환한다.
- 아랍어는 글자의 상·하단이 잘리지 않도록 충분한 행간을 확보한다.
- 스페인어의 악센트 문자 및 구두점이 정상적으로 표시되는지 확인한다.
- 줄바꿈 규칙은 한국어·중국어·일본어와 공백 기반 언어의 차이를 고려해 언어별로 검증한다.
- 본문과 배경의 명도 대비는 WCAG AA를 충족한다.
- 터치 영역은 최소 44×44px을 확보한다.
- 위험 상태는 색상뿐 아니라 아이콘, 제목, 이유 문장으로 중복 전달한다.
- 핵심 행동에는 아이콘만 두지 않고 접근 가능한 이름을 제공한다.

## 10. 차별화 기준

배달의민족에서 참고하는 것은 특정 색상·서체·캐릭터가 아니라 다음의 경험 원칙이다.

- 짧고 사람다운 문장
- 음식에 대한 호기심을 자극하는 표현
- 둥글고 친근하지만 명확한 인터페이스
- 기능을 설명하기보다 사용자가 얻는 즐거움을 먼저 보여주는 구성

한스푼은 여기에 **식이 안전, 다국어 이해, 문화적 배려**를 결합해 독자적인 브랜드로 발전시킨다.
