# 제품 목적과 범위

한스푼은 한국을 여행하는 사람이 자신의 식단을 설명하고, 메뉴를 이해하고, 방문하고 싶은 식당을 발견하도록 돕는다. 브랜드 약속은 “낯선 메뉴도, 안심하고 한 스푼.”이다.

## 사용자와 할 일

- 한국어 메뉴를 읽기 어려운 여행자: 메뉴 이름·설명·원화와 환산 가격을 이해한다.
- 알레르기·종교·채식·기호 조건이 있는 사람: 자기 기준과 관련된 재료를 확인하고 직원에게 질문한다.
- 여행을 준비하는 사람: 지역별 식당·프로필 관련 후기·큐레이션을 살펴보고 찜한다.
- 식사를 마친 사람: 메뉴와 방문 장소를 기록하고 직접 경험한 식단 의사소통에 대해 피드백한다.

## 현재 구현

브랜드 랜딩 → Google 로그인 → 신규 사용자 온보딩 또는 홈 발견 → 풀스크린 지역 지도 → 식당 상세 시트 → 선택적 식당 연결 → 촬영·업로드 → 결과 → 기록 저장 → 스캔 기록 재열기. 입점 식당은 촬영 없이 `/restaurants/:id/menu`에서 현재 프로필로 등록 메뉴 결과를 확인하는 별도 동선을 제공한다. 직원 전달 카드와 기존 인증·프로필·스캔 API 흐름을 유지한다. 원래 홈에 있던 촬영 UI는 `/scan`으로 이동했다.

운영 모드의 홈 미리보기와 풀스크린 지도는 Naver Maps SDK로 렌더링한다. 홈은 18개 지역 칩의 중심 좌표로, 풀스크린 지도는 현재 위치 또는 사용자가 옮긴 지도 중심 좌표로 실제 `POST /api/v1/stores/candidates` 후보를 조회한다. 홈은 지도 핀과 선택한 실제 가게 한 곳을 기존 카드 UI로 보여준다. API에 아직 없는 홈 카드 사진과 후기 집계·커뮤니티 랭킹은 `demo/restaurants.ts`의 명시적인 fixture를 사용하는 임시 구현이다. 6종의 파트너 메뉴 레시피, 입점/레시피 인증 상태, 라이킷과 방문 연결 저장, 환율도 아직 데모 구현이다. 레시피 인증은 파트너가 전체 레시피 정보를 제공했다는 뜻이며 개인별 섭취 안전 보장은 아니다. 실제 스캔의 서버 판정을 변경하지 않는다. `/dev/results-preview`의 메뉴와 확률은 고정 시연 예시다.

## 완료 기준

- 메뉴 목록 중간에 큐레이션을 삽입하지 않는다.
- 확률은 caution 메뉴에서 현재 적용된 프로필과 관련된 회피 재료에만 표시한다.
- safe/danger, 미확인 확률, 무관한 프로필, 범위 밖 값에는 확률을 표시하지 않는다.
- 한국어는 원화, 다른 언어는 원화와 환산 금액을 함께 표시한다.
- 식당 지정 없이도 스캔하고 기록을 저장할 수 있다.
- 식당 지정 기록과 일반 스캔 기록이 하나의 페이지에 표시된다.
- 선택형 후기는 현재 프로필 항목만 표시한다.
- 7개 언어 선택과 아랍어 RTL을 유지한다. 임시 번역의 범위를 기록한다.

## 아직 하지 않는 것

지속적인 위치 추적, 서버 방문 인증, 실시간 환율, AI 오케스트레이션 구현, 실제 후기 수집·랭킹 계산, 제휴 결제·쿠폰 정산. 특정 식당의 안전·할랄 인증을 추정하지 않는다.
